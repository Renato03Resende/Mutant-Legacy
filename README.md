# Mutant Legacy

Um projeto front-end inspirado no universo dos X-Men, desenvolvido com o objetivo de praticar e evoluir meus conhecimentos em desenvolvimento web.

Sobre o projeto

Mutant Legacy é um projeto pessoal desenvolvido inicialmente utilizando HTML e CSS.

A proposta é criar uma experiência visual inspirada no universo dos mutantes, apresentando informações sobre personagens, heróis, vilões, lugares e outros elementos desse universo.

O projeto também servirá como parte do meu processo de aprendizagem. Conforme eu avançar nos estudos, novas tecnologias e funcionalidades serão adicionadas ao site.

Versão atual

Atualmente o projeto possui:

Página inicial;
Navbar personalizada;
Layout com elementos diagonais utilizando clip-path;
Banner principal;
Seções de apresentação;
Estilização personalizada;
Gradientes e efeitos visuais;
Estrutura inicial para futuras páginas.

O projeto ainda está em desenvolvimento.

Ideias futuras

A intenção é que os cards dos personagens evoluam conforme meus conhecimentos em desenvolvimento web aumentarem.

Futuramente, pretendo criar cards interativos contendo modelos 3D dos personagens, com pequenas animações e efeitos visuais.

Ao selecionar um personagem, o usuário poderá acessar uma página dedicada contendo informações como:

História;
Poderes e habilidades;
Afiliações;
Aliados e inimigos;
Curiosidades;
Outras informações relevantes.

Os dados poderão ser organizados utilizando JSON e carregados dinamicamente através de JavaScript.

Objetivo

O principal objetivo deste projeto é colocar em prática meus estudos em desenvolvimento web e acompanhar minha evolução.

Em vez de desenvolver todo o projeto de uma única vez, novas funcionalidades serão implementadas conforme eu estudar novas tecnologias.

Dessa forma, o próprio histórico de commits do repositório também servirá como registro da evolução do projeto.
